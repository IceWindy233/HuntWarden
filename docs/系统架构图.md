# HuntWarden 系统架构图

本文以图示说明当前 Tool Protocol v2 架构。协议对象、字段约束和安全不变量的完整定义见 [`HuntWarden-系统设计文档.md`](HuntWarden-系统设计文档.md)。

## 1. 系统上下文

```mermaid
flowchart LR
  subgraph Controller[控制端]
    GUI[Electron + React GUI]
    TUI[Ink TUI]
    Runtime[Agent Runtime<br/>Capability / Grant / Budget]
    Preset[Preset Executor<br/>确定性最低执行图]
    Tools[8 个只读取证原语<br/>+ 本地 Fact 查询]
    Store[(SQLite<br/>Fact / Coverage / Assessment<br/>Evidence / 回执)]
  end

  Target[目标 Linux 主机<br/>Python Helper v2]
  Model[支持 Tool Call 的模型]
  Intel[可选外部威胁情报]

  GUI --> Runtime
  TUI --> Runtime
  Runtime <--> Model
  Runtime --> Preset
  Preset --> Tools
  Runtime --> Tools
  Tools -->|SSH：固定 argv + stdin JSON| Target
  Target -->|结构化 Observation / SFTP Artifact| Tools
  Tools --> Store
  Runtime -.受控 IOC 富化.-> Intel
```

## 2. 只读调查链路

```mermaid
flowchart TB
  Request[分析师创建 SCAN 任务] --> Identity[绑定目标指纹与 Epoch]
  Identity --> Handshake[Manifest / Capability 握手]
  Handshake --> Minimum[Preset 确定性最低执行图]
  Minimum --> Primitive[Helper 八个白名单原语]
  Primitive --> Observation[Wire Observation]
  Observation --> Validate[Manifest 校验、脱敏、预算核算]
  Validate --> Commit[原子提交 Fact / Edge / ToolRun]
  Commit --> Coverage[Coverage 与 Gap]
  Commit --> Rules[RULE Assessment]
  Commit --> Query[模型通过 query_facts 查询 Model Fact]
  Query --> ModelAssessment[MODEL Assessment]
  Coverage --> Projection[GUI / 报告投影]
  Rules --> Projection
  ModelAssessment --> Projection
```

Helper 只产生观察，不直接形成安全结论。Coverage、RULE、MODEL 和 HUMAN Assessment 相互独立；任何 `PARTIAL`、`ERROR`、`NOT_RUN` 或 `UNKNOWN` 都必须在界面和报告中呈现为不完整。

## 3. 受控处置链路

```mermaid
sequenceDiagram
  participant M as 模型
  participant R as Agent Runtime
  participant A as 分析师
  participant H as 目标端 Helper

  M->>R: 请求 quarantine_file(evidenceRef)
  R->>R: 校验模式、白名单、Evidence 与参数摘要
  R->>A: 请求一次性授权
  A-->>R: 批准
  R->>H: 执行动作（绑定 actionId）
  H->>H: 先记录 STARTED 回执
  H->>H: 原子移动并 chmod 000
  H-->>R: 返回 SUCCEEDED 回执
  R->>R: 授权票据置为 CONSUMED
```

`SCAN` 模式不注册写工具。处置动作必须绑定 `taskId + targetFingerprint + tool + argsDigest + actionId`；发生崩溃且远端回执为 `STARTED` 或 `UNKNOWN` 时，不自动重放，必须由分析师重新核对。

## 4. 数据与信任边界

```mermaid
flowchart LR
  Helper[Helper 私有观察] --> Private[Private Plane]
  Private -->|Manifest 白名单投影| ModelPlane[Model Plane]
  ModelPlane --> Model[模型]
  Private --> Evidence[(Evidence 存储)]
  ModelPlane --> Report[Report Projection]
  Evidence -->|仅元数据和合法引用| Report

  Secret[SECRET / 凭据 / 存储路径] -.禁止.-> Model
  Secret -.禁止.-> Report
```

模型不可访问 Private Fact、Evidence 原始字节、数据库路径、Artifact Token、Spool 路径或 Provider 原始响应。敏感文本读取还需要独立 Grant；私钥、shadow 和凭据库等 `DENIED_TEXT` 不可授权。
