# HuntWarden 后续工作路线

> 更新日期：2026-09-01
>
> 本文只记录当前仍有效的后续工作，不保存已完成的 V1 实施计划。协议与完成定义以 [`HuntWarden-系统设计文档.md`](HuntWarden-系统设计文档.md) 为准，安全门禁和平台声明以 [`支持与验收说明.md`](支持与验收说明.md) 为准。

## 当前基线

- 生产调查链路已完整切换到 Tool Protocol v2；新任务只创建 v2 Epoch，V1 历史任务只读。
- Manifest/Helper 当前版本为 `2.1.0`，五类检测均运行在 Fact、Preset、Coverage 与 RULE/MODEL/HUMAN Assessment 平面上。
- PR 门禁为 125 项通过、37 项环境跳过；五套 Docker Lab 11/11、四套 GUI E2E 16/16、真实 VM smoke 4/4、journald 回归 1/1。
- Ubuntu 24.04 ARM64 已完成五类 × QUICK/STANDARD/DEEP 的 15 个正式 GUI/Provider 任务，152 次正式 ToolRun 无失败，结论为 `PASS_WITH_LIMITATIONS`。
- Manifest `2.1.0` 的 novel malicious + benign 冻结模型评测七项门槛全部通过；语料仍为安全自造夹具。

## 当前限制

- 高推理 Provider 在首跑中出现过一次空响应和两次非法引用；控制端均按预期失败关闭，同配置重跑通过，但稳定性仍不能标记为无条件通过。
- 真实 VM 发布证据目前集中在 Ubuntu 24.04 ARM64。Ubuntu x86_64、Rocky/AlmaLinux、Amazon Linux、完整 Debian systemd VM 尚未验收。
- SSSD/LDAP、`sshd Match` 逐用户/来源上下文、复杂 Apache/PHP-FPM、多版本 Tomcat/JDK 仍缺真实环境覆盖。
- 模型评测样本量不足，不能据当前结果声明真实站点召回率或误报率。
- 文件隔离和账户状态处置都没有恢复动作；`disable_account` 未闭合活动会话与 SSH Key/CA 信任面，因此默认关闭。
- SSH Agent、加密私钥、ProxyJump、Local/Collector/Offline、容器宿主关联与 Windows 接入尚未实现。

## 工作队列

### P0：合并与发布卫生

- 保持 `npm test`、双 TypeScript typecheck、build、lint、生产依赖审计、Helper 编译和 shell 语法全部通过。
- 保持 Docker、GUI、RE2、真实 VM 与模型评测记录可复现；外部环境门禁不得由本地跳过项冒充通过。
- 发布前从最终 tag 的干净工作树重新生成资产和 SHA-256；macOS 签名、公证与自动更新在实现前必须继续标为未支持。

### P1：Provider 稳定性与模型引用质量

- 针对空 assistant、流中停滞和无效 Cursor/Query 引用建立可重复故障注入与 Provider 兼容矩阵。
- 增加更多 novel malicious、benign 与 ambiguous 场景，分别统计事实可达率、召回、误报、非法调用、Token、延迟和失败重试。
- 任何重试不得掩盖首次失败；正式结果继续同时保存首跑与替代样本。

### P1：跨平台真实验证

- 完成 Ubuntu 24.04 x86_64、Debian 12 systemd VM、Rocky/AlmaLinux 9 SELinux Enforcing 与 Amazon Linux 2023 的只读验收。
- 为每个平台记录 Helper Capability、缺失依赖降级、五类 Coverage、Evidence 传输、时区/日志语义和清理状态。
- 验收结果只回填实际执行的平台与架构，禁止从容器或其他架构外推。

### P1：协议与采集契约加固

- 为八个只读原语、维护动词和各 Namespace 固化跨发行版 golden fixture。
- 扩充日志、NSS/SSSD、复杂 Web 配置、包数据库与多版本 JVM collector 契约测试。
- 新增字段或数据源时同步更新 Manifest、Helper、Normalizer、Capability 和协议负例，禁止重新引入按检测问题命名的远程操作。

### P2：检测质量

- 扩展真实 WebShell/内存马样本与 CMS/中间件良性对照，建立可复算的召回率、精确率和规则校准报告。
- 补齐 `sshd -T -C` 的 `Match` 上下文、SSSD/LDAP、复杂 Include/Web Root 推导、更多 JVM/ClassLoader 语料。
- 增加 wtmp/btmp、独立 sudo 日志和更多持久化运行态来源；所有有界采集继续以 CoverageGap 表达未覆盖范围。

### P2：处置闭环

- 完成账户活动会话、`authorized_keys`、`AuthorizedKeysCommand`、SSH CA/principals 的完整信任面处置。
- 实现 `restore_quarantined_file`、`restore_account_state` 和动作后定向复扫。
- 保持逐动作审批、一次性票据、远端回执和 UNKNOWN 不自动重放不变量。

### P3：接入扩展

- 先统一 Transport 的身份、Capability、超时、Evidence、回执与恢复语义，再增加 LocalExecutor、一次性 Collector 和 Offline Import。
- 后续增加 Docker/containerd 宿主与容器关系；Kubernetes 和 Windows 不进入当前发布门槛。
- 支持 SSH Agent、加密私钥与 ProxyJump，并分别验证 Host Key、凭据存储和断线恢复边界。

## 完成口径

每个工作项只有同时满足以下条件才能从本文件删除：

1. 实现和负例测试已经落库，安全失败路径可观察。
2. 对应层级门禁已实际执行，环境跳过不计为通过。
3. `支持与验收说明.md` 和用户文档只声明已验证范围。
4. 测试夹具、临时凭据、VM/容器和产物已清理或明确记录保留原因。
5. 不引入 V1 运行时兼容分支、问题型 Helper 操作或模型可控路径/命令。
