# HuntWarden 版本发布说明

本文合并各版本面向用户的发布摘要。完整逐项变更仍以根目录 [`CHANGELOG.md`](../CHANGELOG.md) 为准；当前支持边界以 [`支持与验收说明.md`](支持与验收说明.md) 为准。

## v0.2.0（2026-09-01）

v0.2.0 将生产调查链路完整切换到 Tool Protocol v2。新任务只运行 v2 Epoch；模型使用八个受限取证原语，Helper Observation 经 Manifest 校验后原子写入 Fact Store，再由本地查询、Coverage 和 RULE/MODEL/HUMAN Assessment 独立呈现。

### 主要变化

- Manifest/Helper 升级到 `2.1.0`，补充委派规则、SSH 有效信任配置、固定 file Scope 与 `package_db` 有界验证链路。
- 删除运行时 v1 operation map、旧问题型工具面和旧 Finding 结论平面；v0.1.x 历史任务仅保留只读元数据、Evidence 和已有报告。
- 五类检测迁移为版本化 Preset、CoverageRun 与不可互相覆盖的 Assessment。
- Object、Cursor、Query、Evidence、Grant、Budget 与 Action Receipt 全部绑定 task、epoch 和目标身份；不兼容引用与越权请求失败关闭。
- 增加 Fact Store、Dataset Registry、RE2 双平台矩阵、v1→v2 能力等价门禁、四套 GUI E2E、真实 VM/journald 验收和冻结模型评测。
- 默认处置白名单只开放 `quarantine_file`；`disable_account` 因信任面和恢复链路不完整而保持关闭。

### 验证与限制

- PR、构建和静态门禁通过；Docker Lab 11/11、Debian 动态场景 5/5、GUI E2E 16/16。
- Ubuntu 24.04 ARM64 上完成 smoke 4/4、journald 1/1、模型评测 7/7，以及五类 × QUICK/STANDARD/DEEP 的 15 个正式任务。
- Provider 首跑出现过一次空响应和两次非法引用，控制端均按预期处理，因此综合结论为 `PASS_WITH_LIMITATIONS`。
- 这是破坏性展示升级：v0.1.x Finding 不再由 v2 UI/TUI/报告读取，但数据库行不会被删除。
- 目标端必须使用匹配的 Helper `2.1.0`；恢复动作、更多发行版与 JVM 版本仍待实现或验收。

## v0.1.1（2026-08-21）

v0.1.1 是 Electron GUI 补丁版本，不改变安全边界、Helper 协议、模型调用方式或任务数据格式。

- 修复任务侧栏和长详情内容无法滚动的问题，并补充语义化区域与无障碍标签。
- 修正 Grid/Flex 最小高度约束，使固定窗口内形成真实溢出区域。
- 发布脚本只收集版本号精确匹配的 ZIP/DMG，避免历史构建产物混入。
- 自动化测试 131 项通过、34 项跳过，GUI 调查 E2E 4/4 通过。

## v0.1.0（2026-08-20）

首个公开版本提供五类 Linux 主机专项检测、可追溯 Evidence/Finding、逐动作审批、崩溃恢复和版本化 Markdown 报告。

### 核心能力

- WebShell、Tomcat 9/JDK 17 Java 内存马、后门账户、Linux 持久化与 Linux 入侵分诊。
- 安恒威胁情报只富化当前任务内已经观测或由分析师预置的 IOC。
- SSH Host Key 严格绑定；Helper 只接受固定操作和 JSON 参数，不提供任意命令执行。
- `SCAN` 没有写工具；`REMEDIATE` 的每个动作均需一次性授权。
- 原始 Evidence 不进入模型上下文，采集缺口不会被描述为安全。

### 历史限制

v0.1.0 仅支持单台 Linux 主机直连 SSH；缺少 root、YARA、日志或 JDK Attach 时能力会降级；macOS arm64 开发包未签名或公证。该版本的 V1 验收结果已经被 v0.2.0 的 V2 基线取代，不作为当前支持证据。

## 安装与校验

从对应 GitHub Release 下载 `.zip` 或 `.dmg` 以及 `SHA256SUMS`，在 macOS 上执行：

```bash
shasum -a 256 -c SHA256SUMS
```

从源码复现时切换到对应 tag，再执行：

```bash
npm ci
npm run build
npm test
npm run probe:build
```

发布资产必须从最终 tag 对应的干净工作树生成。开发包尚未使用 Apple Developer ID 签名或公证；只调查你拥有或明确获授权的主机。
