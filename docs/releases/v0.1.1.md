# HuntWarden v0.1.1 Release Notes

> 历史发布快照：本文只描述 v0.1.1，不代表当前 V2 支持状态；当前状态以 [`SUPPORT_MATRIX.md`](../SUPPORT_MATRIX.md) 为准。

HuntWarden v0.1.1 是面向 Electron GUI 的补丁版本，修复调查任务较多或详情内容较长时无法正常滚动的问题。本版本不改变安全边界、Helper 协议、模型调用方式或任务数据格式。

## 修复内容

- 调查任务侧栏现在始终保留可见滚动槽，任务数量超过窗口高度后可正常滚动浏览。
- 任务详情内容区采用独立滚动区域，长调查过程、Finding、Evidence 与报告内容不会再撑出窗口。
- 修正 Grid/Flex 子项的最小高度约束，确保两个区域能够在固定窗口布局内形成真实溢出。
- 为侧栏和详情区补充语义化区域及无障碍标签。
- 发布脚本只收集版本号精确匹配的 ZIP/DMG，防止本机历史构建产物混入本版本资产与校验清单。

## 验证范围

- 独立 Electron 布局压力测试创建 30 个任务，侧栏可视高度为 524 px、内容高度为 1707 px，并确认侧栏与详情区均能实际改变滚动位置。
- 默认自动化测试通过：131 项通过、34 项跳过。
- GUI 调查 E2E 4/4 通过，其中滚动用例创建 20 个额外任务并断言真实滚动。
- `build`、Lint、core/renderer typecheck 与 GitHub CI 均通过；正式资产从最终发布提交的干净工作树生成。

## 安装与校验

从本 Release 下载 macOS arm64 的 `.zip` 或 `.dmg` 以及 `SHA256SUMS`，然后执行：

```bash
shasum -a 256 -c SHA256SUMS
```

这些开发包未使用 Apple Developer ID 签名或公证，首次启动时 macOS 可能显示安全提示。

源码复现：

```bash
git clone https://github.com/IceWindy233/HuntWarden.git
cd HuntWarden
git checkout v0.1.1
npm ci
npm run build
npm test
```

完整功能、安全边界和已知限制请参阅 [v0.1.0 Release Notes](v0.1.0.md)。只调查你拥有或明确获授权的主机。
