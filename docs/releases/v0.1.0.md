# HuntWarden v0.1.0 Release Notes

HuntWarden 是面向安全分析师的 AI Linux 主机安全调查与受控处置 Agent。本版本以“模型扩展调查不能突破确定性安全边界”为核心，提供五类主机专项检测、可追溯 Evidence/Finding、逐动作审批、崩溃恢复和手动版本化报告。

## 核心能力

- WebShell：Web Root、近期候选、YARA、日志与进程关联、文件 Evidence 和受控隔离。
- Java 内存马：Tomcat 9/JDK 17 组件枚举、来源检查与只读 Class Dump，不自动清除或重启 JVM。
- 后门账户：特权账户、SSH Key、委派与登录历史，并提供受控账户禁用。
- Linux 持久化：Cron、systemd、SSH、Shell 及扩展启动项，只读取证。
- Linux 入侵分诊：进程树、FD/maps/socket、删除后运行、近期文件、包完整性、认证事件和时间线。
- 安恒威胁情报：仅富化当前任务内已观测或分析师预置 IOC，不允许模型提交任意查询目标。

## 安全边界

- 目标通过 SSH Host Key 与端口严格绑定，未知指纹只能人工信任，变更或撤销 Key 直接阻断。
- 目标端 Helper 只接受固定操作与 JSON 参数，不提供 Bash/Shell 或任意命令执行。
- `SCAN` 模式没有写工具；`REMEDIATE` 每个动作都需要与目标、参数和 Action ID 完全绑定的一次性授权。
- 原始二进制 Evidence 不进入模型上下文；敏感凭据始终脱敏或保留在系统安全存储。
- `ERROR`、`PARTIAL`、`NOT_CHECKED` 不等于安全，报告会明确保留覆盖缺口。

## 已知限制

- 首版仅支持单台 Linux 主机的直连 SSH，不支持 SSH Agent、加密私钥、ProxyJump、Local/Collector、Windows 或 Kubernetes。
- 完整能力需要 root Helper；YARA、auditd/journald、JDK Attach 或 systemd 缺失时会降级为 `PARTIAL/ERROR`。
- 自动处置仅覆盖 WebShell 文件隔离和账户禁用；Java、持久化与通用分诊只读取证。
- macOS arm64 开发包未使用 Developer ID 签名或 Apple 公证，首次启动会出现系统安全提示。
- 当前只生成 Markdown 报告，不提供 PDF、集中式多主机 Hunt 或多 Agent 调度。

## 安装与校验

从 GitHub Release 下载 `.zip` 或 `.dmg` 以及 `SHA256SUMS`，在 macOS 上执行：

```bash
shasum -a 256 -c SHA256SUMS
```

源码复现：

```bash
git clone https://github.com/IceWindy233/HuntWarden.git
cd HuntWarden
git checkout v0.1.0
npm ci
npm run build
npm test
npm run probe:build
```

## 安全提示

只调查你拥有或明确获授权的主机。首次观察到的在线 Host Key 不能作为带外信任依据；真实主机优先使用 `SCAN`，在复核 Finding、Evidence 与覆盖缺口之后再考虑处置。
