# HuntWarden v0.2.0 Release Notes

HuntWarden v0.2.0 将生产调查链路完整切换到 Tool Protocol v2。新任务只运行 v2 Epoch；模型使用八个受限取证原语组合调查，Helper Observation 经 Manifest 校验后原子写入 Fact Store，再由本地查询、Coverage 和 RULE/MODEL/HUMAN Assessment 独立呈现。

## 主要变化

- Manifest/Helper 升级为 `2.1.0`，后门账户路径覆盖 sudoers、doas、polkit 委派规则和 `sshd -T` 默认连接上下文；Linux 分诊增加固定 file Scope 与 `package → owns_file → verify(package_db)` 有界链路。
- 删除运行时 v1 operation map、问题型工具面、旧 Finding 结论平面与 Helper v1 分发入口；v0.1.x 历史任务仅保留只读任务元数据、Evidence 和已生成报告。
- 五类检测迁移为版本化 Preset、CoverageRun 与不可相互覆盖的 RULE/MODEL/HUMAN Assessment。
- Object、Cursor、Query、Evidence、Grant、Budget 和 Action Receipt 全部绑定 task、epoch 与目标身份；不兼容引用和越权请求 fail-close。
- 增加版本化 Fact Store、Dataset Registry、RE2 双平台矩阵、五类 v1→v2 能力等价门禁、四套 GUI E2E、真实 VM/journald 验收和冻结模型能力评测。
- 默认处置白名单只开放 `quarantine_file`。`disable_account` 未覆盖活动会话、SSH Key/CA 信任面和恢复验证，因此默认关闭。

## 发布验收

- 默认测试：30 个文件、125 项通过；10 个环境项、37 项跳过。
- 静态与构建门禁：生产依赖审计、Lint、core/Renderer 双 typecheck、build 和 Java Probe 全部通过。
- Docker：Ubuntu 22.04 五套固定 Lab 11/11、Debian 12 动态场景 5/5 通过。
- GUI：investigation、remediation、recovery、Sensitive-read Grant 四套 E2E 共 16/16 通过。
- 平台语义：macOS ARM64 与 Ubuntu 22.04 ARM64 RE2 实际匹配及不支持语法 fail-close 路径通过。
- Ubuntu 24.04 ARM64：Helper `2.1.0` smoke 4/4、journald 身份/generation 回归 1/1 通过。
- 真实 Provider：Manifest `2.1.0` 冻结模型评测七项门槛 7/7 通过。
- 真实 GUI/Provider：五类检测 × QUICK/STANDARD/DEEP 共 15 个正式任务完成，152 次 ToolRun 零失败；因另有一次 Provider 空响应和两次被 fail-close 的错误引用首跑，综合结论为 `PASS_WITH_LIMITATIONS`。

完整证据见 [`V2_INVARIANT_VERIFICATION.md`](../V2_INVARIANT_VERIFICATION.md)、[`VM_UBUNTU_24.04_ARM64_V2_P1_2026-08-30.md`](../acceptance/VM_UBUNTU_24.04_ARM64_V2_P1_2026-08-30.md)、[`MODEL_EVAL_P1_2026-08-30.md`](../acceptance/MODEL_EVAL_P1_2026-08-30.md) 与 [`GUI_PROFILE_MATRIX_V2_P1_2026-09-01.md`](../acceptance/GUI_PROFILE_MATRIX_V2_P1_2026-09-01.md)。

## 兼容性与已知限制

- 这是破坏性数据展示升级：v0.1.x 的 Finding 不再由 v2 UI/TUI/报告读取，数据库行不会被删除；历史 Evidence 与已生成报告仍保留。
- 目标端必须安装与本版本匹配的 Helper `2.1.0`；旧 Helper 不兼容即拒绝任务。
- `restore_quarantined_file` 与 `restore_account_state` 尚未实现，真实目标优先使用 `SCAN`。
- Ubuntu 24.04 ARM64 为当前真实主机发布基线；Ubuntu x86_64、Rocky/AlmaLinux、SSSD/LDAP、复杂 Apache/PHP-FPM 和更多 JVM 版本仍待扩展验收。
- macOS ARM64 资产尚未使用 Apple Developer ID 签名或公证，首次启动可能出现系统安全提示。

当前支持边界以 [`SUPPORT_MATRIX.md`](../SUPPORT_MATRIX.md) 为准。

## 安装与校验

从本 Release 下载 `.zip` 或 `.dmg` 以及 `SHA256SUMS`，然后执行：

```bash
shasum -a 256 -c SHA256SUMS
```

源码复现：

```bash
git clone https://github.com/IceWindy233/HuntWarden.git
cd HuntWarden
git checkout v0.2.0
npm ci
npm run build
npm test
```

发布资产必须从 `v0.2.0` Tag 对应的干净工作树生成。只调查你拥有或明确获授权的主机。
