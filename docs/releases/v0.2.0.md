# HuntWarden v0.2.0 Release Notes

HuntWarden v0.2.0 将生产调查链路完整切换到 Tool Protocol v2。新任务只运行 v2 Epoch；模型使用八个受限取证原语组合调查，Helper Observation 经 Manifest 校验后原子写入 Fact Store，再由本地查询、Coverage 和 RULE/MODEL/HUMAN Assessment 独立呈现。

## 主要变化

- 删除运行时 v1 operation map、问题型工具面、旧 Finding 结论平面与 Helper v1 分发入口；v0.1.x 历史任务只读。
- 五类检测迁移为版本化 Preset、CoverageRun 与可追溯 Assessment。
- 增加 task/epoch/target 绑定的 Object、Cursor、Query、Evidence、Grant、Budget 和 Action Receipt。
- 增加 RE2 双平台矩阵、五类 v1→v2 能力等价测试、四套 GUI E2E、真实 VM journald 验收与冻结模型能力评测。
- 默认处置白名单只开放 `quarantine_file`。`disable_account` 未覆盖活动会话、SSH Key/CA 信任面和恢复验证，因此默认关闭。

## 已知限制

- v2 后门账户最低覆盖尚未采集 sudoers/doas/polkit 委派配置及有效 sshd 信任配置。
- `restore_quarantined_file` 与 `restore_account_state` 尚未实现，真实目标优先使用 SCAN。
- 真实平台发布证据集中在 Ubuntu 24.04 ARM64；其他发行版和架构不能据此宣称已验证。
- macOS 产物尚未签名、公证，本版本发布资产必须从最终 tag 的干净工作树重新构建并记录 SHA-256。
